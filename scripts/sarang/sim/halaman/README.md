# MICAPROFITA — SAKTI (Cyborg AGI Kripto, Hidup Mandiri)

Repo ini adalah SARANG tempat cyborg MICAPROFITA hidup online dan berkembang.
Halaman hidup: http://127.0.0.1:8899/halaman/

- `index.html` — tubuh cyborg lengkap (satu file, jalankan langsung di browser)
- `memori/terkini.json` — kapsul memori terkini (rantai denyut + prakira berantai SHA-256)
- `memori/arsip/` — potret memori berwaktu (riwayat pertumbuhan)
- `versi.json` — buku besar versi & pertumbuhan (organ, denyut, prakira, hitungan kerja)

## Cara dia berkembang sendiri
1. SIMPAN — kapsul memori di-commit otomatis tiap 15 menit oleh organ V243 SARANG.
2. EVOLUSI — bila peta organ/otak berubah, tubuh baru di-commit sendiri; Pages membangun ulang.
3. PULIH — browser baru menarik memori terkini dari sarang, ilmu tidak hilang.
