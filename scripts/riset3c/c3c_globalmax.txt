All Collections Platform Features Global Max Open Positions Settings Global Max Open Positions Settings This short article describes how the Global Max Open Positions parameter works and where you can use it. August 11, 2026 Table of contents The Max Open Positions setting controls the maximum number of strategies all bots can have open cumulatively at once. Any new trade signals beyond this limit will be ignored or canceled until an existing strategy closes. This feature helps manage risk, control capital allocation, and prevent excessive trading. Examples: 1) If you have configured 10 Signal Bots and set the "Max Open Positions" parameter to 10, with each bot currently running one active strategy, the system will reach its capacity limit. As a result, any subsequent strategy will not be executed until an existing strategy is closed or the maximum limit is adjusted. 2) If you have created 11 DCA bots and set the "Max Open Positions" parameter to 10, the system will execute strategies for the first 10 bots as intended. Once the limit of 10 active strategies is reached, the attempt of 11th DCA bot to create a new strategy will be declined, and the bot will be stopped. How to Set Up Max Open Positions in the DCA Bot The Max Open Positions parameter is located on the top next to the Create Bot button in the DCA Bot tab. Set your preferred value and press Save. How to Set Up Max Open Positions in the Signal Bot The Max Open Positions parameter is located on the top next to the Create Bot button in the Signal Bot tab. Set your preferred value and press Save.
